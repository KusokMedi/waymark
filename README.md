# Waymark

**Know before you go.**

A modern, open-source dashboard for U.S. Department of State travel advisories.

## Features

- Global destination directory
- Search, sorting, and filtering
- List and card views
- Destination details with regional records
- Favorites and personal watchlist
- Light, dark, and system themes
- Automatic data synchronization
- Responsive, accessible UI

## Links

- Website: https://kusokmedi.github.io/waymark/
- Application: https://kusokmedi.github.io/waymark/app/
- Repository: https://github.com/KusokMedi/waymark

## Data source

Travel advisories are published by the U.S. Department of State. Waymark is an independent project and is not an official U.S. government product. Advisories are written for U.S. citizens, nationals, and legal residents and are not a universal safety assessment.
